## Basic Keylogger (Python)

The objective of this task was to create a *basic keylogger program that records and logs keystrokes* while understanding the ethical considerations involved in monitoring tools.

## Features

- Records keystrokes using Python
- Saves logs into a file
- Displays activity in the terminal
- Active window detection
- Clipboard monitoring
- Automated screenshot capture
- Multithreaded execution

## Technologies Used

- Python
- pynput
- pyautogui
- pyperclip
- pygetwindow
- pillow
- threading

## How to Run

Install dependencies:

pip install -r requirements.txt

Run the Program:

python main.py
